LumineEconomyBridge 機能ガイド

LumineEconomyBridge は Minecraft のスコアボード経済を Python バックエンドと Web ダッシュボードに橋渡しするプラグインです。本ページでは基本的な使い方から応用操作まで懇切丁寧に解説します。

1. 初期設定

  1. サーバーに LumineEconomyBridge.jar を導入して再起動します。
  2. backend/ ディレクトリで python main.py を実行し FastAPI サーバーを起動します。
  3. plugins/LumineEconomyBridge/config.yml の api.token とバックエンド環境変数 LE_TOKEN を同じ値に設定します。
  4. 必要に応じて LE_API_BASE や MAPCOLOR_URL を環境変数で指定します。

2. プレイヤー向けコマンド

  • /le wallet : 自分の口座残高を表示。口座が無い場合は自動作成されます。
  • /le pay <player> <amount> [currency] : 他プレイヤーへ送金。
  • /le balance [currency] [player] : 指定した通貨やプレイヤーの残高確認。
  • /le money top [currency] [page] : 残高上位一覧を表示 (10 人/ページ)。
  • /le history <player> [limit] : 最近の取引履歴を表示。
  • /le shop : ショップ樽を受け取り設置すると自動でショップが作成されます。シフトクリックで売却も可能。
  • /le search <item> [currency] [min] [max] : 公開ショップを検索。
  • /le lang <code> : 表示言語を切り替え (例: /le lang ja)。

3. Web ダッシュボードの利用

  1. ゲーム内で /le weblink を実行してワンタイムトークンを取得します。
  2. ブラウザで /register にアクセスし、ユーザー名・パスワード・トークンを入力して登録します。
  3. /login からログインすると、残高確認やショップ管理、ショップ検索などが利用できます。

ダッシュボードではアカウント検索・編集、通貨供給量の確認、取引履歴のフィルタリング、バックアップ管理、コマンドログ閲覧などの高度なツールも提供しています。

4. ショップ機能

  • /le shop create <id> : 任意の ID でショップ樽を作成。
  • /le shop add <id> <qty> <price> <name> : 在庫を追加。
  • /le shop take <id> <item> <qty> : 在庫を回収。
  • /le shop price <id> <name> <currency> <amount> [more...] : 価格を設定。
  • /le shop partner add <id> <player> : 共同オーナーを追加。
  • /le search <item> [currency] [min] [max] : ショップを検索。
  • プレイヤーは在庫のあるショップにアイテムをシフトクリックすることで売却できます。

5. 管理者向け機能

  • /le money give <player> <currency> <amount> : プレイヤーへ資金を発行。
  • /le money take <player> <currency> <amount> : 資金を没収。
  • /le currency create <id> [symbol] : 新しい通貨を作成。
  • /le currency manager add <id> <player> : 通貨管理者を追加。
  • /le currency tax <id> <rate%> : 税率を 0.1% 単位で設定。
  • /le currency treasury <id> <account> : 税の納付先アカウントを指定。
  • /le account create <id> : システムアカウントを作成。
  • /le account connect <user> <system> : ユーザーにシステムアカウントを紐付け。
  • /le admin add <player> : ダッシュボード管理者に追加。
  • /le backup / /le restore <file> : データベースのバックアップ・復元。
  • /le undo / /le redo : 最近の操作を取り消し/やり直し。

6. 応用例

以下は複数の機能を組み合わせた応用例です。

  • 複数通貨の運用: /le currency create で通貨を追加し、/le currency manager add で管理者を指定するとゲーム内で独自の経済圏を構築できます。
  • 税収システム: /le currency tax と /le currency treasury を設定すると取引ごとに自動で税が徴収され、指定アカウントへ入金されます。
  • ショップ網の構築: ショップ樽を複数設置し /le shop partner add で共同運営者を追加すると大規模なマーケットが作れます。
  • Web ダッシュボードによる監査: 管理者はダッシュボードで取引履歴を絞り込み、異常な送金や税収の推移を確認できます。バックアップ管理を定期的に行うことで万一のトラブルにも備えられます。

より詳細なコマンド一覧は USAGE.md、ショップ運営の詳細は SHOP_HELP.md を参照してください。
